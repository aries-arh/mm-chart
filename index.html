Panduan Penggunaan EasyMMC

Tutorial langkah demi langkah untuk membuat Man-Machine Chart, membaca waktu menganggur, dan melakukan simulasi perbaikan.

Bagian 1 · Cara Cepat Membuat Grafik (Mode Sederhana)

Langkah 01

Pengaturan Dasar & Template

  1. Aplikasi selalu terbuka dalam keadaan bersih (kosong). Anda dapat langsung mengisi data baru, atau memilih template contoh (1 Operator · 1 Mesin, 1 Operator · 2 Mesin, 2 Operator · 2 Mesin).
  2. Isi Nama Proses, Jumlah Operator, Jumlah Mesin, dan Target Waktu 1 Siklus (misalnya 60 detik).
  3. Klik ikon ? di sebelah label bila membutuhkan penjelasan istilah.
Langkah 02

Tambah Langkah Kerja

  1. Pilih Pelaku Kerja (Operator atau Mesin) dan Jenis Aktivitas sesuai warna.
  2. Ketik Nama Kegiatan atau pilih dari daftar saran otomatis.
  3. Atur Durasi dengan tombol cepat -5 / -1 / +1 / +5, lalu klik + Tambah Langkah Kerja.
Langkah 03

Edit Urutan & Geser Grafik

  1. Di daftar kiri, tarik kartu langkah ke atas atau bawah untuk menukar urutan, atau klik -1 / +1 untuk ubah durasi.
  2. Di Grafik Vertikal (waktu berjalan dari atas ke bawah), tarik balok ke atas/bawah untuk menggeser waktu mulai.
  3. Tarik garis kecil di bagian bawah balok untuk memanjangkan atau memendekkan durasi.
Langkah 04

Baca KPI & Kotak Saran Kaizen

  1. Pantau 3 kartu ringkasan di atas: Total Waktu 1 Siklus, Kesibukan Operator (%), dan Kesibukan Mesin (%).
  2. Area abu-abu bertuliskan Kosong menunjukkan waktu menganggur (idle time).
  3. Periksa Kotak Saran Kaizen di bawah grafik untuk melihat deteksi bentrok jadwal dan saran penghematan waktu.

Bagian 2 · Arti 4 Warna Jenis Aktivitas

Kerja Mandiri (Hijau)

Operator bekerja di luar mesin, misalnya mengambil bahan, memeriksa kualitas, atau merapikan produk jadi.

Kerja di Mesin (Biru)

Operator berinteraksi langsung dengan mesin, seperti memasang part ke jig, menekan tombol Start, atau mengeluarkan hasil.

Mesin Jalan Otomatis (Oranye)

Mesin bekerja memproses barang secara otomatis tanpa perlu dipegang operator.

Menunggu / Menganggur (Abu-abu)

Waktu kosong saat operator menunggu mesin selesai atau mesin menunggu dilayani operator.

Bagian 3 · Fitur Lapangan, Simulasi, Laporan & Mode Lanjutan

Stopwatch Lapangan (Time Study)

Jika belum memiliki angka durasi, buka tab Stopwatch, pilih pelaku & jenis aktivitas, tekan Mulai saat mengamati lini produksi, tekan Catat Langkah tiap pergantian kerja, lalu klik Masukkan ke Grafik.

Simulasi Before vs After

Klik Jadikan Kondisi Awal (Before) di Kotak Saran Kaizen sebelum mengubah jadwal. Setelah Anda menggeser balok atau memindahkan aktivitas kerja mandiri, buka tab Before vs After dan klik Ambil Grafik Aktif ke After untuk melihat selisih efisiensi.

Proyek Tersimpan di Browser

Bila ingin menyimpan beberapa skenario di komputer yang sama tanpa mengunduh file, klik Simpan Proyek di pojok kanan atas dan kelola daftarnya di tab Proyek Tersimpan.

Mode Lanjutan (Teknik Industri)

Klik sakelar Mode Lanjutan di kanan atas ringkasan bila perlu mengatur Multi-Cycle (hingga 20 siklus), Waktu Mulai Siklus yang tumpang tindih, tabel input presisi, dan Timeline Horizontal.

Bagian 4 · Mulai Bersih, Simpan File & Lanjutkan Pekerjaan (Import / Export)

Clean Start

Aplikasi Selalu Mulai Bersih

  1. Setiap kali dibuka di web browser atau tab baru, data selalu dalam keadaan bersih (kosong) agar tidak tercampur data lama atau contoh.
  2. Refresh halaman (F5) pada tab yang sama tetap menjaga pekerjaan sementara Anda, sedangkan menutup tab/browser akan mereset kembali menjadi bersih.
Simpan

Simpan Pekerjaan Sebelum Menutup

  1. Klik Simpan JSON di bagian bawah panel kiri untuk mengunduh file cadangan lengkap (nama proses, pelaku, target siklus, dan seluruh siklus).
  2. Atau klik Export CSV di kanan atas grafik bila ingin menyimpan dalam format tabel sekaligus bisa diimpor ulang.
Lanjutkan

Import File untuk Melanjutkan

  1. Buka aplikasi di browser atau komputer mana saja dalam keadaan bersih.
  2. Klik Import JSON atau Import CSV di bagian bawah panel kiri, lalu pilih file simpanan Anda sebelumnya untuk langsung melanjutkan.
Laporan

Export PNG, PDF & Excel

  1. Pilih format tampilan di atas grafik (Grafik Vertikal, Timeline Horizontal, atau Tabel Angka).
  2. Klik Export PNG, Export PDF, atau Export Excel — hasil unduhan otomatis mengikuti format grafik yang sedang aktif.
